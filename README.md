# EDUVERSE — The Learning Adventure

Game edukasi 3D open-world multiplayer berbasis web untuk siswa SD (Kurikulum Merdeka).
Siswa bermain langsung dari Chrome di HP, tablet, atau komputer — tanpa instalasi.
Guru mengelola sesi, soal, dan memantau permainan dari Dashboard Guru (tablet).

Branch `main` adalah baseline stabil. Pengembangan berjalan di branch `dev/eduverse-html3d`
dan digabung ke `main` melalui Pull Request.

Lihat README pada branch pengembangan untuk instruksi instalasi lengkap.
